# 神椿TCG tokenカウンター（非公式）

神椿TCG（KAMITSUBAKI CARD GAME）のプレイ補助ツールです。ブラウザで開くだけで使え、ログインは不要です。スマホ・タブレット・PCに対応しています。

**URL:** https://kmtbk-tools.github.io/kamitsubaki-tcg-tools/

## できること
- VOL（10点で勝利）、VOLノイズ、魔力 α・β・Ω の管理。丸やトークンをタップ、または −／＋ で操作
- 上限の変更（カード効果で上限が下がったとき。重複分だけ下げられ、超えた分は自動で消失）
- LIMITED の使用前／使用後
- 3Dで転がるサイコロ（目で表示、「4以上」「偶数」の判定つき）。1〜5個まとめて振れて、4以上・偶数の個数と合計を表示（「真偽」のような効果に）
- 先攻・後攻決めは2人がそれぞれサイコロを振る（1台なら同時にはじける）
- ターン数・手番の表示、ターン終了、先攻・後攻決め、引き直し回数の記録、操作ログ
- 1台で遊ぶときの「↶ 戻す」（直前の操作を取り消し。ターン終了直後は通知から戻せます）
- 簡潔表示：スクロールなしの1画面。スマホは縦向き（VOLは5個×2段）・横向きどちらにも対応
- 表示は「2人並べる」と「自分だけ」（自分のパネルだけをできるだけ大きく。1台のときは⇅で表示するプレイヤーを切り替え）
- 対面表示：1台を2人で挟んで使うとき、奥の人のパネルとボタンの文字を逆向きにも表示
- 一度開けば電波がなくても起動できます（ホーム画面に追加するとアプリのように使えます）
- 画面を消さない（対応端末）

## はじめての方へ
- **1台で遊ぶ**：「設定・共有」→「1台で遊ぶ」。端末をテーブルに置いて向かい合わせで使います。丸をタップするか −／＋ で数値を変え、手番が終わったら「ターン終了」。
- **オンラインで遊ぶ**：「設定・共有」→「オンラインで遊ぶ」→「対戦を作る」で4文字のコードが出ます。招待リンクかコードを相手に伝えてください（公開の投稿には書かず、DMなどで）。
- **ホーム画面に追加**：iPhone（Safari）は共有ボタン →「ホーム画面に追加」、Android（Chrome）はメニュー →「ホーム画面に追加」。

アプリ内でも「設定・共有」の一番上の「使い方」から同じ説明が見られます。

## 遊び方
右上の「設定・共有」から遊び方を選びます。

- **1台で遊ぶ**：この端末を2人で使います。状態はその端末に保存されます。
- **オンラインで遊ぶ**：「対戦を作る」で4文字のコードが出ます。相手は招待リンクを開くか、コードを入力して参加します。
  - 端末同士を直接つなぐ方式（WebRTC / PeerJS）です。対戦を作った人（ホスト）の端末が中継役になります。
  - 初期設定では自分の数値だけ操作できます。ホストは「相手の数値も操作できるようにする」に切り替えられます（ログに操作した人が残ります）。
  - ターン終了は手番のプレイヤーだけが押せます。
  - ページを再読み込みしたり、アプリを切り替えて戻ったりしても、自動でつなぎ直します。
  - 一部の社内ネットワークなどではつながらない場合があります。
