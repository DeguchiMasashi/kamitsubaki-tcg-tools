# 神椿 LIVEカウンター

神椿TCG（KAMITSUBAKI CARD GAME）のプレイ補助ツールです。ブラウザで開くだけで使え、ログインは不要です。スマホにも対応しています。

## できること
- VOL（10点で勝利）、VOLノイズ（最大5）、魔力 α・β・Ω（各上限5）の管理。上限を超える生成は警告
- ターン数・手番・フェーズ（ドロー／アクト／エンド）と、各フェーズでやることの表示
- サイコロ（4以上・偶数の判定つき）、先攻・後攻決め、引き直し回数の記録
- 操作ログ
- 表示切り替え：「自分を大きく」／「2人並べる」（対面表示で相手側を180°回転）
- 画面を消さない設定（対応端末のみ）、ホーム画面に追加してアプリのように使用可能

## 遊び方
- **1台で**：そのまま使えます。状態はその端末に保存されます。
- **オンライン対戦**：設定 → オンライン対戦 →「対戦を作る」で4文字のコードが出ます。相手は招待リンクを開くか、コードを入力して参加します。
  - 端末同士を直接つなぐ方式（WebRTC / PeerJS）です。対戦を作った人（ホスト）がページを閉じると同期が止まります。開き直すと「前回の対戦に戻る」で再開できます。
  - 一部の社内ネットワークやモバイル回線ではつながらない場合があります。

## ファイル
- `index.html` 本体
- `peerjs.min.js` 通信ライブラリ（PeerJS 1.5.4, MIT License）
- `manifest.json`, `icon*.png`, `icon.svg` ホーム画面用

非公式のファンメイドツールです。ルールの詳細は[公式サイト](https://tcg.kamitsubaki.jp/)を参照してください。
